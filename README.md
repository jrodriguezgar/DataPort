DataMolder es una potente y flexible librería de Python diseñada para gestionar colecciones de registros de datos. Ofrece una manipulación de datos eficiente, con seguridad de tipos, validación de datos robusta y una amplia gama de operaciones funcionales y utilidades analíticas.

### Características Principales

* **Seguridad de Tipos y Validación de Datos:** Define y aplica tipos de datos para cada columna, junto con reglas de validación personalizadas para garantizar la integridad de los datos.
* **Gestión Flexible de Columnas:** Añade, elimina, renombra y reordena columnas dinámicamente.
* **Operaciones de Datos Mutables:** Añade, actualiza y elimina filas con validación en tiempo real.
* **Navegación con Cursor y Marcadores:** Navega fácilmente por los registros utilizando un cursor o marcadores nombrados.
* **Bloqueo de Filas y Columnas:** Protege datos específicos de modificaciones accidentales o no autorizadas.
* **Operaciones Funcionales:** Incluye métodos eficientes para filtrar, mapear y ordenar datos.
* **Análisis y Métricas:** Obtén estadísticas de columnas, valores distintos y métricas de uso de memoria.
* **Transformación de Datos:** Soporte para operaciones de `pivot` y `unpivot` para remodelar tus datos.
* **Concatenación de Datos:** Combina `DataMolder`s horizontal (por columnas) o verticalmente (añadiendo filas).
* **Manejo de Errores Detallado:** Excepciones personalizadas para errores de validación, tipos, restricciones y columnas no encontradas.
